# Mood & Light — Interactive Mockup

Vite + React prototype of the product flow (not the Expo app yet).

## Flow

1. Name  
2. **Card fan** moods — “Tap a card to pull it forward · tap again to open”  
3. Subcategories  
4. **Threads** — references only (Quran / Hadith)  
5. **Reading** — Arabic, English, meaning, reflection · Previous / Next · **Report**

## Run

```bash
cd mockup
npm install
npm run dev
```
